## Example cognitive roster

`examples/agents` contains the configuration used to develop Ghost itself.

It demonstrates a three-resource QAC hierarchy:

- Wraith — economical execution and investigation
- Shade — general-purpose engineering and reasoning
- Veil — scarce high-capability reasoning

The names and number of agents are illustrative. Ghost and QAC do not depend on
these identities; users can define their own resources and prompts.
